# 小黑盒bot

小黑盒bot 是运行在 AstrBot 内的小黑盒社区插件。它可以使用 AstrBot 已配置的人设和会话上下文回复评论与私信，也支持自主巡帖、图文发布、账号内容读取、评论统计和 WebUI 管理。

插件独立运行，不需要额外部署桥接服务或数据库服务。

> [!WARNING]
> 本插件使用的不是小黑盒面向第三方开放的稳定公共 API。接口变化、账号状态和平台风控都可能影响功能。建议先使用测试账号和用户允许列表，并保持较低频率。

## 功能

- 使用 AstrBot 人设、会话历史和兼容的 LLM 请求钩子回复小黑盒评论与私信。
- 回复明确提及机器人的评论，以及可选的自己帖子下普通评论、好友私信和陌生人私信。
- 自主浏览推荐流，由模型选择帖子并决定评论或跳过。
- 提供 30 个 LLM 工具，用自然语言读取社区、管理当前账号、发布图文和分析评论。
- 支持评论、被回复评论、原帖和私信图片；支持网络、本地、Base64 图片和 GIF 首帧。
- 使用 SQLite 归档评论与私信，通过 WebUI 查看状态、队列、统计、明细和评论洞察。
- 提供写入权限、可选逐次确认、限速、去重、单帖回复上限和发送结果不确定保护。

## 环境要求

- AstrBot `>=4.24.5,<5`
- Python 3.10 或更高版本
- 一个可用的小黑盒账号
- 一个已在 AstrBot 中配置的 LLM 提供商
- 如需识别图片，所选模型必须支持视觉输入

默认配置不会立即让账号公开发言：允许列表为空，私信自动回复、自主巡帖和 LLM 写工具均为关闭状态。

## 快速开始

### 1. 安装

在 AstrBot 插件管理页使用仓库地址安装：

```text
https://github.com/Whereis-Alice/astrbot_plugin_xhhrobot
```

也可以下载 [最新 Release](https://github.com/Whereis-Alice/astrbot_plugin_xhhrobot/releases/latest) 安装。手动部署时，将插件目录放到 AstrBot 的 `data/plugins/` 下，并安装 `requirements.txt` 中的依赖。

### 2. 完成基础配置

首次使用建议只修改以下配置。表中名称与 AstrBot 插件配置页一致。

| 配置页中文名 | 配置键 | 建议 |
| --- | --- | --- |
| 回复模型 | `ai.provider_id` | 选择负责自动回复和巡帖决策的模型。 |
| 回复人设 | `ai.persona_id` | 选择现有 AstrBot 人设；留空时使用默认会话或默认人设。 |
| 启用 AstrBot 标准事件 | `event_bridge.enabled` | 建议保持开启，让评论和私信进入正常消息链。 |
| 允许回复的用户 ID | `filters.allowed_user_ids` | 初次只填写测试用户的小黑盒 ID。 |
| 允许回复所有用户 | `filters.allow_all_users` | 测试稳定后再开启。 |
| 回复自己帖子下的普通评论 | `filters.reply_to_own_post_comments` | 控制是否回复自己帖子下没有明确提及机器人的评论。 |
| 单个自己帖子自动回复上限 | `filters.max_replies_per_own_post` | 防止热门帖子无限堆积队列，`0` 表示不限。 |
| 允许回复时使用外部搜索 | `ai.allow_external_search` | 允许模型在需要时调用 AnySearch 等已启用的搜索工具。 |

完整字段说明请直接查看插件配置页。配置项已经按账号、模型、回复范围、私信、巡帖、工具、图片、统计、通知和稳定性分组。

### 3. 扫码登录

在插件 WebUI 的“扫码登录”页面生成二维码，或由 AstrBot 管理员发送：

```text
/小黑盒登录
```

使用手机小黑盒 App 扫码确认，再检查状态：

```text
/小黑盒状态
```

推荐将“手动 Cookie（可选）”留空。Cookie 等同账号凭据，不要发送到聊天、日志、问题反馈或公开仓库。

### 4. 小范围验证

保持“允许回复所有用户”关闭，只在“允许回复的用户 ID”中加入测试用户。可以先生成回复但不发布：

```text
/小黑盒测试 帖子ID 测试消息
```

自主巡帖也应先使用预览：

```text
/小黑盒逛帖 预览
```

## 自动回复

评论和私信默认作为 AstrBot 标准事件处理，因此会使用当前人设、会话上下文和兼容的 LLM 请求钩子。小黑盒专用规则可以写在“额外回复规则”，不需要复制整份人设。

### 回复范围

| 场景 | 行为 |
| --- | --- |
| 用户在任意帖子中明确提及机器人 | 用户通过允许范围检查后回复。 |
| 用户在机器人自己发布的帖子下普通评论 | 开启“回复自己帖子下的普通评论”后回复，无需明确提及机器人。 |
| 用户在其他账号帖子下普通评论 | 不回复。 |
| 机器人自己的评论 | 忽略，避免自我回复循环。 |

“允许回复的用户 ID”“允许回复所有用户”和“禁止回复的用户 ID”同时作用于评论与私信。屏蔽列表优先级最高。

每次生成还会提供服务器当前日期、时间、星期和时区。开启“允许回复时使用外部搜索”后，模型可以自行判断是否需要调用当前已启用的搜索工具；搜索失败时会继续普通生成，不会把搜索过程发到小黑盒。

### 图片与表情

评论回复的视觉上下文按“当前评论图片、被回复评论图片、原帖图片”的顺序加入消息链，并自动去重。图片会先由插件下载和校验，再交给 AstrBot；失效图片会被跳过，文字内容仍会继续生成。GIF 会转换为首帧 PNG。

“HTTP 图片优先原字节上传”默认开启，可减少缩略图被再次转存的问题。本地图片仅允许 AstrBot 管理员从插件允许的目录上传，不要把 `/`、`C:\\` 或整个用户目录加入允许范围。

小黑盒表情会在发送前规范为有效标识符，例如 `[cube_狗头]` 会转换为 `[cube_doge]`。完整列表见 [小黑盒表情对照表](./emoji_reference.md)。

### 私信自动回复

开启“启用私信自动回复”后，插件会处理新的好友私信；“回复陌生人私信”控制陌生人入口。首次启用默认只建立基线，不回复已有历史消息。

建议保留默认的随机轮询、单用户冷却和 24 小时额度。若平台返回“禁止发送消息行为”，插件会跳过当前消息并临时暂停后续私信外发，但仍继续收信和归档。该错误不一定表示手机 App 也无法私信。

### 自主巡帖

开启“启用自动巡帖”后，模型会定时读取推荐流、选择帖子、读取正文并决定评论或跳过。建议先开启“巡帖仅预览”，确认选帖和口吻后再允许发布。

自主巡帖受巡帖间隔、单轮评论上限、24 小时评论上限、作者冷却、帖子去重和内容安全检查保护。它是独立的后台功能，不受 LLM 写工具开关控制，也不会逐条要求聊天确认。

## LLM 工具

开启“启用小黑盒 LLM 工具”后，用户通常不需要说工具名，可以直接用自然语言要求机器人操作。例如：

```text
搜索最近讨论 AstrBot 的帖子，列出标题和帖子 ID。
查看帖子 123456 的正文、图片和热门评论。
看看谁回复了当前账号，以及最近收藏了哪些帖子。
分析帖子 123456 的评论，告诉我主要话题、情绪和建议。
把刚才的评论分析做成小黑盒终端卡片。
先写一篇图文帖草稿，不要发布。
```

### 工具启用规则

- 社区公开读取工具在“小黑盒 LLM 工具”开启后可用。
- 账号状态、通知、私信、数据库和洞察属于私密读取，默认仅 AstrBot 管理员可用。
- 发帖、评论、互动、删除和私信发送还需要开启“启用写操作工具”。
- 本地草稿工具还需要开启“启用本地草稿箱工具”并重载插件。
- “每次写操作都要求确认”开启时，用户原消息必须包含配置的确认词；关闭后，明确的自然语言请求可直接执行。
- 来自小黑盒评论或私信的外部事件默认不能调用账号工具，避免提示注入。

### 社区读取工具

| 工具 | 主要参数 | 用途 |
| --- | --- | --- |
| `xhh_get_feed` | `offset`, `pull` | 读取社区推荐动态。 |
| `xhh_search` | `query`, `search_type`, `offset`, `limit` | 搜索帖子、用户、游戏、标签或商城内容。 |
| `xhh_get_post` | `link_id`, `page`, `limit`, `sort_filter` | 读取帖子正文、图片和评论页。 |
| `xhh_get_sub_comments` | `root_comment_id`, `last_value` | 分页读取根评论下的子评论。 |
| `xhh_get_user_profile` | `user_id` | 读取用户公开资料。 |
| `xhh_get_user_activity` | `user_id`, `activity_type`, `offset`, `limit` | 读取用户发布的帖子、评论或动态。 |
| `xhh_get_user_relations` | `user_id`, `relation`, `offset`, `limit` | 读取用户的粉丝或关注列表。 |
| `xhh_get_topics` | `query` | 列出或搜索发帖话题，取得 `topic_id`。 |
| `xhh_get_emojis` | 无 | 读取当前可用的小黑盒表情。 |

### 当前账号与统计工具

以下工具属于私密读取，默认仅 AstrBot 管理员可用。

| 工具 | 主要参数 | 用途 |
| --- | --- | --- |
| `xhh_status` | 无 | 查看登录账号、后台任务、队列和工具状态，并刷新账号资料。 |
| `xhh_get_mentions` | `offset`, `limit` | 读取当前账号收到的提及消息。 |
| `xhh_get_notifications` | `kind`, `offset`, `limit` | 统一读取提及、自己帖子评论与回复。 |
| `xhh_get_favorite_folders` | 无 | 读取当前账号的收藏夹目录和 `folder_id`。 |
| `xhh_get_my_favorites` | `offset`, `limit` | 读取当前账号收藏的帖子。 |
| `xhh_get_remote_drafts` | 无 | 读取小黑盒服务端草稿箱。 |
| `xhh_get_direct_messages` | `user_id`, `limit`, `sequence`, `include_strangers` | 列出私信会话或读取指定用户的私信历史。 |
| `xhh_comment_stats` | 时间、帖子、用户、来源、状态等筛选 | 统计 SQLite 中收到和发出的评论。 |
| `xhh_search_comment_archive` | 筛选项、`direction`, `limit` | 查询具体评论归档记录。 |
| `xhh_comment_insights` | `mode`, `topic`, 筛选项 | 自动探索评论话题和情绪，或按指定主题定向统计；支持查看进度和取消。 |
| `xhh_render_comment_insight_card` | `theme`, `resolution` | 把最近完成的洞察渲染成图片并发送到当前会话。 |

查看当前账号自己发布的帖子、评论和动态时，先用 `xhh_status` 取得账号 ID，再调用 `xhh_get_user_activity`。

`xhh_comment_insights` 的 `mode` 支持 `run`、`status`、`cancel`。用户只说“分析评论”“看看大家都在说什么”时，应将主题和关键词留空，让工具自动探索；只有询问特定问题时才填写 `topic`。卡片主题为 `terminal`、`cyberpunk`、`editorial`、`command`，清晰度为 `standard`、`high`、`ultra`。

### 写操作工具

以下工具需要开启“启用写操作工具”。写操作默认仅 AstrBot 管理员可执行。

| 工具 | 主要参数 | 用途 |
| --- | --- | --- |
| `xhh_publish_post` | `title`, `body`, `topic_ids`, `hashtags`, `image_urls`, `content_blocks` | 发布普通图文帖；最多两个话题、五个标签。 |
| `xhh_create_comment` | `link_id`, `text`, `root_id`, `reply_id`, `image_urls` | 评论帖子或回复指定评论。 |
| `xhh_set_favorite` | `link_id`, `favorite`, `folder_id` | 收藏或取消收藏帖子。 |
| `xhh_set_like` | `target_type`, `target_id`, `liked` | 点赞或取消帖子、评论点赞。 |
| `xhh_set_follow` | `user_id`, `followed`, `link_id` | 关注或取消关注用户。 |
| `xhh_delete_post` | `link_id` | 删除当前账号自己发布的帖子。 |
| `xhh_send_direct_message` | `user_id`, `text`, `image_sources` | 发送私信文本和多张网络或本地图片。 |

逐次确认开启时，推荐先让机器人返回预览，再发送：

```text
确认执行小黑盒操作，发布刚才那一版。
```

关闭“每次写操作都要求确认”后不需要确认词，但管理员权限、允许列表、写入冷却和重复操作保护仍然生效。

### 本地草稿工具

以下工具需要开启“启用本地草稿箱工具”；保存和删除还需要开启写操作工具。

| 工具 | 主要参数 | 用途 |
| --- | --- | --- |
| `xhh_get_drafts` | `draft_id`, `limit` | 列出或读取插件本地草稿。 |
| `xhh_save_draft` | `draft_id` 及帖子字段 | 新建或更新本地草稿，不发布到小黑盒。 |
| `xhh_delete_draft` | `draft_id` | 删除本地草稿，不影响服务端草稿或已发布帖子。 |

本地草稿保存在 AstrBot 服务器的 SQLite 中，与小黑盒 App 的服务端草稿互不相同。

### 图文发帖

`xhh_publish_post` 和 `xhh_save_draft` 支持按顺序排列的 `content_blocks`：

```json
[
  {"type": "text", "text": "第一段纯文本"},
  {"type": "html", "html": "<p><strong>重点</strong></p>"},
  {"type": "image", "url": "https://example.com/image.jpg"}
]
```

HTML 只允许基础排版、强调、列表、引用、代码和公开 HTTP(S) 链接。脚本、样式、事件属性、私网链接和未知标签会被拒绝。普通正文中的真实换行、字面量 `\\n`、`<br>` 和段落标签会在发送前转换为正确换行。

## WebUI 与评论洞察

插件 WebUI 提供：

- 扫码登录、清除登录和登录状态。
- 当前账号资料、头像、后台任务、队列和自动功能状态。
- 停止或启动后台任务，取消全部或指定帖子的待处理评论队列。
- 评论和私信 SQLite 统计、筛选、分页、总页数与消息详情。
- 评论自动探索、定向统计、任务进度、取消分析和洞察图片卡片。

评论洞察只分析插件启用后实际归档的外部评论，不会自动抓取全部历史。打开页面不会消耗模型额度；只有启动语义分析时才调用“评论洞察模型”。

在群聊或私聊中可以直接说：

```text
分析帖子 123456 的评论，看看大家都在说什么。
统计最近 7 天有多少人在吐槽价格。
把刚才的分析做成小黑盒终端高清卡片。
```

分析完成后，结构化结果会交回当前 AstrBot 会话，由当前人格、上下文和兼容的请求钩子组织最终回答。

## 数据与安全

- 评论、私信和可选本地草稿保存在插件数据目录的 SQLite 文件中，不需要外部数据库。
- 扫码凭据、设备 ID、游标、队列和巡帖状态使用 AstrBot 插件存储。
- Cookie、代理凭据、数据库和缓存不会包含在 Release 安装包中。
- “在 WebUI 显示消息正文”关闭后，页面不会返回评论和私信原文。
- 发帖、评论、回复、删除和私信发送等写请求不会因临时 HTTP 失败自动重发，避免重复操作。
- 只读接口和模型瞬时故障会有限重试；最终失败时可通过“发生错误时通知”发送到指定“通知会话 UMO”。

### 可选 SOCKS5 代理

“家庭 SOCKS5 代理”可以让本插件访问小黑盒的流量单独经过代理，不影响 AstrBot 平台消息、模型请求或服务器其他流量。

```text
socks5://用户名:密码@主机:端口
```

建议通过 Tailscale、WireGuard 或 SSH 隧道连接私有代理，不要把 SOCKS5 端口直接暴露到公网。代理设备必须保持开机和联网。代理只能改善网络路径，不能绕过平台规则或账号限制。

## 常见问题

### 已登录，但机器人不回复

先运行 `/小黑盒状态`。新安装时允许列表为空且“允许回复所有用户”关闭，因此不会回复任何人。还要确认后台任务已启动、用户未被屏蔽，并且评论满足明确提及机器人或位于机器人自己帖子下的规则。

### 人设或其他 LLM 请求钩子没有生效

确认“启用 AstrBot 标准事件”已开启，并检查“回复人设”或默认会话人设。第三方插件如果限制平台、会话或触发条件，还需要允许 `xhhrobot` 平台及相应小黑盒会话。

### 机器人看不到评论图片

确认“视觉上下文图片上限”不是 `0`，并选择支持视觉输入的模型。纯文本模型无法识别图片内容。失效或返回 404 的单张图片会被跳过。

### 热门帖子导致队列堆积或评论频率异常

设置“单个自己帖子自动回复上限”，然后在 WebUI 取消指定帖子队列，或执行 `/小黑盒清空队列 帖子ID 确认`。平台已经提示评论频率异常时，应等待限制自然解除，不要反复重试。

### 小黑盒 HTTP 500、非 JSON 500 或模型 502/530

这通常是小黑盒读取接口、模型服务商或 Cloudflare Tunnel 的临时故障，不代表账号被风控。插件会对安全读取和模型决策进行有限重试；写操作仍保持单次提交。持续失败时检查服务器网络、模型服务和可选代理。

### 私信提示“禁止发送消息行为”

这表示当前网页 API 私信请求被小黑盒拒绝，不一定影响手机 App。先确认“手动 Cookie（可选）”为空，再执行 `/小黑盒退出` 和 `/小黑盒登录` 建立干净登录态。仍被拒绝时应等待限制解除，不要连续测试。

### 出现重复回复

检查 AstrBot 中是否同时存在旧版本、重复插件目录或另一个小黑盒自动回复插件。不同插件实例无法共享去重状态。
